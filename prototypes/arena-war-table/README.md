# Crown Arena War Table

A playable three-hero Arena prototype for testing visible rival intent, energy budgeting, active assists, cooldowns, and explainable simultaneous combat resolution.

## Commands

```powershell
npm run dev --workspace @wildcrown/arena-war-table
npm run test:combat --workspace @wildcrown/arena-war-table
npm run build --workspace @wildcrown/arena-war-table
```

The prototype keeps its existing ChatGPT Sites packaging while also participating in the root Vercel-ready showcase build.
